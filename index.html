Alguns projetos...

Vts
VivaTShirt/repositories

A VivaTShirt é uma plataforma de e-commerce especializada no setor de vestuário, desenvolvida com uma arquitetura moderna em Node.js no backend e uma interface responsiva em HTML5 e CSS3 (Tailwind). O diferencial estratégico do projeto é sua integração nativa com a API da Shopee, permitindo que o cliente gerencie estoque, pedidos e sincronização de produtos de forma centralizada. Utilizando o banco de dados MySQL para garantir a integridade das transações e o gerenciamento de clientes, a aplicação oferece um fluxo de venda otimizado, unindo a autonomia de uma loja própria com a visibilidade de um dos maiores marketplaces do mercado.

Srp
Projeto-Interdisciplar-SRP/repositories

"Sistema de Reservas para Paróquias", desenvolvimento de um sistema web completo para gestão de viagens paroquiais, incluindo controle de ônibus, reservas de assentos e acompanhamento das viagens. A solução foi projetada com foco em usabilidade e organização operacional.

Green
figma/greenpeace

Desenvolvimento do protótipo de um site institucional para uma ONG com foco em sustentabilidade. O projeto tem como objetivo conectar pessoas à causa ambiental, promovendo ações educativas em escolas sobre temas como sustentabilidade, conservação da biodiversidade e proteção dos oceanos, reforçando a educação como agente de transformação social.

Tafe

Aplicativo mobile voltado à segurança do trabalho na construção civil, o TAFE (Terminal de Anotação e Fiscalização de Eventos) veio com o objetivo de registrar e monitorar acidentes. A solução contribui para garantir os direitos dos trabalhadores e aumentar a transparência entre colaboradores e empresas.

Este é um projeto em PHP de uma API CRUD para gerenciamento de produtos e usuários, desenvolvido utilizando a arquitetura PSR-4 com o Composer. O frontend que consome essa API pode ser encontrado aqui. O projeto foi criado como parte de uma atividade avaliativa na FATEC, onde estudo.

vdanviel/metablog

Um projeto desenvolvido com a stack MERN, que consiste em uma rede social onde os usuários podem postar conteúdos com mídias, seguir outros usuários e personalizar seus perfis. O projeto adota o conceito de monorepositório, reunindo tanto o lado do servidor quanto o lado do cliente em um único repositório. Além disso, ele está dockerizado, permitindo que o ambiente seja iniciado facilmente com um simples comando docker-compose.

vdanviel/serene-app

Serene é um aplicativo psicológico desenvolvido com o objetivo de explorar e pesquisar o potencial da IA. Criado em React Native, com um servidor em Symfony, o app gera cinco perguntas aleatórias sobre ansiedade. Após o usuário responder ao questionário, o aplicativo fornece um diagnóstico preliminar indicando, com base nos dados fornecidos, se há sinais de ansiedade. As inteligências artificiais utilizadas no projeto foram extraídas da plataforma Hugging Face.

vdanviel/laravel-solid

Esta é uma API Laravel integrada com Google Auth e Stripe (para soluções financeiras da web), projetada como uma API de e-commerce que permite aos usuários adicionar produtos a um carrinho e comprá-los, com todos os processos de pagamento gerenciados pelo Stripe. A API é construída usando princípios SOLID e PostgreSQL como seu banco de dados. O projeto usa JWT para autenticação, webhooks Stripe para processamento de pagamento, envio de e-mail para notificações, TDD para desenvolvimento orientado a testes e inclui testes de ponta a ponta. Além disso, o Scribe é usado para salvar e gerenciar a documentação da API.

Im
vdanviel/imaginenote

Este projeto está na forma de SPA e faz requisições a uma API própia, escrita em Laravel ImagineNote API. Ele é feito em Vue.js, uma aplicação de notas, onde é possível fazer anotações e guardar todo tipo de mídia nessas anotações. As mídias são salvas no Firebase Storage.
